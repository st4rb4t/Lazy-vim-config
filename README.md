# Lazy-vim-config

This is my Lazy Vim config that I am using currently 

I have added induvidual lua configs for catagorising depending on their use for easier readability and modularity 

### Plugins: 


#### Cmp.lua

  ##### **nvim-cmp**
    Used for autocompletion 

#### Editors.lua

  ##### **nvim-autopairs**
    QOL plugin for autoparing for brackets and quotation marks 

  ##### **comment.nvim** 
    Enables quickly commenting and uncommenting based on set keybinds 

  ##### **nvim-surround**
    Allows you to quickly add, delete or chanage characters around statements 

#### Hobby.lua 

  ##### **nvim-dap**
    Brings debugging support to Neovim using the Debug Adapter Protocol (DAP)

#### lsp.lua
  ##### **nvim-lspconfig**
    Makes it easy to set up Language Server Protocol (LSP) support in Neovim

#### notes.lua 
  ##### **luarocks.nvim**
    Dependency for neorg 

  ##### **neorg**
    Similar to emacs org mode but not quite the same. Org mode reminagined for nvim native notetaking 

  ##### **obsidian.nvim** 
    Enables use of editing obsidian vault within nvim which enables cross good useage for cross devices       and platforms 

  ##### **nvim-orgmode**
    More the the traditional emacs org mode within nvim but can be said it doesn't quite the same level       of power as it does natively within emacs 

#### telescope.lua 
  ##### **telescope.nvim**
    Powerful fuzzy finder framework 

##### treesitter.lua 
  ##### **nvim-treesitter**
     
      Parses code into sayntax tree and understands it structure which is a major quality of life upgrade 

#### ui.lua 
  ##### **lualine.nvim**
    Customisable statusline plugin showing info like git branch, file path, current mode, errors and          warnings 

  ##### **neotree.nvim**
    File explorer side bar enabling directory browsing and file modification much like :Explore
    
  ##### **gitsigns.nvim**
    git integration which shows inline changes + for added lines, ~ for modified lines and _ for deleted lines
